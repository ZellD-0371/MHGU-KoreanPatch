# MHGU-KoreanPatch
글로벌판인 Generation Ultimate 1.4.0버전

원래 일본판으로 제작됐던 한글패치파일을 포팅함

[PC포팅 버전](https://github.com/morerokk/MHGURecomp) mods 폴더 혹은
에뮬레이터 모드 적용 혹은
스위치 커펌후 모드 적용(테스트 안해봄)

- **일반 / HD** : HD버전은 메모리 사용량 다소 증가

### FontTool 
- 원하는 폰트를 적용해 게임에 적용할 수 있는 툴입니다.

### Forge 설정창 -> 한국인 전용 방
- v1.1.0이후 추가된 기능으로 별 기능은 아닙니다만 한국인들만 보고 싶은 사람들을 위해 버튼을 누르고 재시작하면 해당 버튼을 누른 사람들끼리 집회소에서 만나게 됩니다. (언제든 다시 공개 매칭으로 돌아갈 수 있음.)

### 일부 번역 수정
- v1.1.0 이후 일부 번역을 월드 이후 시리즈의 정식 한국어 번역을 참고하여 바꿨습니다. 예) 샤갈마가라 -> 샤가르마가라, 도스맛카오 -> 도스마카오, 광폭 이블조 -> 미친 이블조

### 호환되는 모드
- [KatSmithy](https://gamebanana.com/mods/737929)

- KatSmithy 모드 이용 시 고려해야 할 사항 :
  - `KatSmithy_MenuText`는 설치하지 말아주세요.
  - KatSmithy 폴더 안에 있는 `strings_ko.tsv`을 지워주세요. (`string_ko.tsv`는 이미 우리 모드 폴더내에 포함되어 있습니다.)
  - v1.0.6 이전부터 KatSmithy를 설치해서 실행했던 유저라면 무기 목록이 일부 영어로 나올 수 있습니다. 이를 해결하기 위해 Recomp save폴더에서 `tree_names.txt`를 지워주세요. (지워도 다시 생성되는데 다시 생성될때는 한국어로 나옵니다.)
